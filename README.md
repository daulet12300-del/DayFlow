# DayFlow: как выложить и передать

В папке лежит готовый сайт. Серверов, регистрации и аналитики в нём нет, все данные человека хранятся у него на телефоне.

Файлы:
- `index.html` — само приложение
- `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — значок и установка на экран «Домой»
- `sw.js` — работа без интернета

Все файлы должны лежать в одной папке и открываться по адресу вида `https://…/`. Просто открыть `index.html` двойным щелчком можно, но установка на телефон и офлайн-режим тогда не заработают.

## Шаг 1. Выложить в интернет

Выберите один из двух способов.

### Способ А. Netlify Drop (быстрее, 2 минуты)

1. Распакуйте архив. Получится папка `dayflow-site`.
2. Откройте https://app.netlify.com/drop и перетащите эту папку в окно браузера.
3. Через несколько секунд появится адрес вида `что-то-там.netlify.app`.
4. Привяжите сайт к бесплатному аккаунту (сервис предложит это на странице). Без этого сайт может удалиться примерно через час.
5. Адрес можно поменять на более понятный: Site configuration → Change site name.

### Способ Б. GitHub Pages (бесплатно, адрес остаётся навсегда)

1. На github.com создайте репозиторий, например `dayflow`. Выберите Public: для бесплатных Pages это нужно. Личных данных в файлах нет.
2. Нажмите Add file → Upload files и перетащите все файлы из папки `dayflow-site`. Нужны именно файлы, а не папка целиком: `index.html` должен лежать в корне репозитория.
3. Нажмите Commit changes.
4. Откройте Settings → Pages. В разделе Build and deployment выберите Source: Deploy from a branch, ветку `main` и папку `/ (root)`. Нажмите Save.
5. Через 1–2 минуты внизу страницы появится адрес `https://ВАШ-ЛОГИН.github.io/dayflow/`.

## Шаг 2. Проверить у себя

Откройте адрес в Safari на своём iPhone, добавьте на экран «Домой» (см. ниже), введите имя и создайте пару задач. Закройте приложение и откройте снова. Если всё на месте, можно отправлять ссылку.

## Шаг 3. Что отправить человеку

Перешлите ссылку и этот текст:

> Это DayFlow, органайзер для задач, привычек и заметок.
> 1. Откройте ссылку в Safari.
> 2. Нажмите кнопку «Поделиться» (квадрат со стрелкой), затем «На экран “Домой”» и «Добавить».
> 3. Дальше открывайте DayFlow только с иконки на экране. Не пользуйтесь им через Safari: данные там хранятся отдельно.
> 4. Введите имя и нажмите «Начать».
> 5. Раз в пару недель заходите в «Настройки → Резервная копия → Скачать файл» и сохраняйте файл в «Файлы» или отправляйте себе в мессенджер. Это защита на случай, если телефон потеряется или приложение придётся поставить заново.

## Что важно знать про данные

- Прогресс хранится только на телефоне человека. Вы его не видите, и он не видит ваш.
- Если удалить иконку с экрана «Домой» или очистить данные сайтов в Safari, прогресс пропадёт. Спасает только резервная копия.
- Safari и установленная иконка хранят данные отдельно. Если человек начал вводить задачи в Safari, а потом установил иконку, на иконке будет пусто. Переносится так: в Safari «Настройки → Резервная копия → Скачать файл», затем в приложении с иконки «Резервная копия → Выбрать файл».
- Смена телефона: старая копия восстанавливается тем же способом.

## Уведомления

Напоминания появляются, пока приложение открыто. Системные уведомления можно включить в «Настройки → Разрешить системные уведомления», но только если приложение установлено на экран «Домой» (iOS 16.4 и новее). Когда приложение закрыто, iPhone не гарантирует их доставку. Честно предупредите об этом человека.

## Как обновить приложение

1. Замените `index.html` (и другие изменённые файлы) в Netlify или в репозитории.
2. В `sw.js` поменяйте `dayflow-v1` на `dayflow-v2` (потом `v3` и так далее). Тогда телефоны подтянут новую версию.
3. Данные людей при обновлении не теряются.

## Если что-то не работает

- Нет пункта «На экран “Домой”»: ссылка открыта не в Safari. Откройте её в Safari.
- Приложение не обновляется: закройте его полностью (смахните вверх в переключателе) и откройте снова. Проверьте, что поменяли версию в `sw.js`.
- Не отображаются шрифты без интернета: приложение использует системный шрифт, на работу это не влияет.
